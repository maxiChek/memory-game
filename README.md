# Memory Game

Игра на поиск пар: игрок открывает карточки и запоминает их расположение,
чтобы найти все совпадения за наименьшее число ходов.

Задание: [rolling-scopes-school/tasks → memory-game](https://github.com/rolling-scopes-school/tasks/tree/master/tasks/memory-game)

## Демо

Деплой: https://maxichek.github.io/memory-game/

## Возможности

- Поле 4×4 из 16 карточек: 8 пар одинаковых SVG-иконок.
- Карточки перемешиваются случайным образом при загрузке и в каждой новой игре.
- Открытие двух карточек — один ход. Совпавшие пары остаются открытыми,
  несовпавшие закрываются через 900 мс.
- Счётчики ходов и найденных пар.
- Модальное окно победы с итоговым числом ходов.
- Таблица лидеров: до 10 лучших результатов, хранятся в `localStorage`,
  доступны после перезагрузки страницы.
- Сброс игры без перезагрузки страницы, отмена таймера несовпавшей пары.
- Все HTML-элементы создаются через `document.createElement` (в `<body>` только `<script>`).
- Никаких сторонних UI-библиотек и фреймворков.

## Технологии

- JavaScript (ES-модули), без фреймворков.
- Vite — сборщик и dev-сервер.
- CSS Grid и CSS 3D-трансформации для анимации карточек.
- GitHub Actions — автоматический деплой на GitHub Pages.

## Локальный запуск

Требуется Node.js 20+.

```bash
git clone https://github.com/maxiChek/memory-game.git
cd memory-game
git checkout memory-game
npm install
npm run dev
```
